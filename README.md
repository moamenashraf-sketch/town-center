# Town Center — Al Arid, Riyadh

Static bilingual (AR/EN) landing page for Town Center by Blacksand, built on the Thimarya / Al Maha template.

- `index.html` + `style.css` — no build step
- `thank-you.html` — post-submit page with a conversion-pixel placeholder (Meta / Google / Snap / TikTok)
- Content and images come from the Town Center brochure. The brochure is English-only, so all Arabic text is a translation and needs client review.
- The lead form currently redirects to `thank-you.html` without sending data: connect a backend/CRM (see the TODO in `index.html`).
